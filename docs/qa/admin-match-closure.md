# 管理员结束比赛验收

2026-10-08，使用独立本地 PostgreSQL 验收库、生产构建和虚拟账号复测。浏览器使用 1440 × 900 桌面视口和 390 × 844 手机视口，未在生产库中创建测试数据。

## 入口与规则

入口为比赛详情页 → 赛事管理 → 结束比赛。仅平台管理员可见，只适用于已发布赛程、正在进行的 V2 正式纯小组赛，覆盖单打、双打和团体赛。普通比赛发起人、快速比赛、Legacy 比赛、报名中的比赛和包含淘汰赛的赛事不使用此入口。

管理员先查看剩余对局名单，再勾选确认结束。未提交有效成绩的剩余对局统一作废，已确认成绩、积分、ELO、个人胜负与场次、已有报名结算均保留。有待确认成绩或待处理更正时，先处理这些记录；系统不提供跳过它们的结束操作。

## 实际验证

- 普通比赛发起人的独立会话可以进入赛事管理，但看不到结束比赛按钮。
- 未勾选确认直接提交，浏览器阻止操作；关闭弹窗和按 Escape 均不修改比赛，对焦回到入口。
- 单打案例原有 6 场、1 场已确认：从手机页面确认后比赛显示已结束，另 5 场显示已作废，2:0 的原成绩仍可查看。数据库核对所有参赛者的积分、ELO、胜负和场次均未变化，并写入实际管理员的结束记录。
- 团体案例同样从手机页面收尾，保留 3:1 的原成绩并作废另外 5 场；所有队员的统计均未变化。结束按钮位于队伍管理列表之前，手机视口 y=586.5、高 44，无需向下查找队伍列表。
- 在预览之后由应用服务修改一场对局，页面提交被拒绝，提示重新预览；重新核对后显示最新开赛状态，原错误和确认勾选被清除。
- 有待确认成绩时，弹窗先显示需处理的对局并隐藏结束确认表单。点击处理入口后进入待确认成绩标签，跨越两次自动刷新仍保持该标签和链接位置。
- 手机核对弹窗宽 358、高 750，位于 390 × 844 视口内；整页宽 390，无横向溢出。剩余对局列表单独滚动，确认和返回按钮可见。

截图及数据核对记录位于本地 `output/playwright/admin-finish-match/`，不提交账号文件、截图中的测试数据和临时数据库文件。
