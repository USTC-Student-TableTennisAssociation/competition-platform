# 比赛报名身份资料

发布正式比赛时可勾选收集姓名和中国大陆居民身份证号，默认关闭，既有比赛不受影响。收集要求在发布时确定。单打由选手本人填写，双打由双方分别提交，团体由队员在建队或入队时提交。格式校验不核验号码是否由公安机关签发，也不比对姓名和号码归属。

管理员从“管理员控制台 → 报名身份资料”选取比赛、参赛者，完成后台二次验证后可查看该人提交的资料。只有已完成报名的有效名单出现在查看入口；每次成功读取均记录管理员、赛事和参赛者标识，日志不含姓名或身份证号。普通参赛者、队长、比赛发布者的身份本身不授予读取权限。

## 配置

在服务器私有运行环境中配置 `REGISTRATION_IDENTITY_KEY`，值为随机 32 字节的标准 Base64 编码（可用 `openssl rand -base64 32` 生成）。仅服务端需要，禁止使用 `NEXT_PUBLIC_` 前缀或提交到仓库。未配置有效密钥时，不能新建启用收集的赛事；普通赛事照常使用。

姓名、号码按赛事及参赛者用 AES-256-GCM 加密保存，账号资料、公开名单及普通报名导出不包含这些字段。数据库备份也包含这些密文。请把密钥单独存入受控的密钥备份，并验证恢复流程。直接替换密钥会使先前记录不可读；轮换应先做备份并安排解密、重新加密迁移。删除赛事或账号时，关联资料会随之删除。
